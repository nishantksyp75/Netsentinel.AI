# Curated knowledge sources

This directory holds short, project-approved defensive notes for retrieval. Add only material your institution permits you to use, with source URL, publication date, section, and a short summary. Do not put credentials, private incidents, or confidential network details here.

The built-in knowledge entries cite NIST SP 800-61r2, MITRE ATT&CK, OWASP Logging Cheat Sheet, and CISA DDoS guidance. They provide context to an analyst; they do not override model evidence or authorize an action.
